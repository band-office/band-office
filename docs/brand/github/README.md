# GitHub presentation assets

This directory contains the launch-ready Band Office artwork for GitHub.

## Files

- `avatar-1024.png` — exact approved mark for the organization avatar
- `readme-hero.png` and `.svg` — repository README hero
- `organization-banner.png` and `.svg` — organization profile header
- `social-preview.png` and `.svg` — 1280 × 640 repository social preview

The SVG compositions reference the adjacent approved raster mark; they do not trace or reinterpret it.

## Live setup

1. Upload `avatar-1024.png` as the `band-office` organization avatar.
2. Create the public `band-office/.github` profile repository from the prepared organization-profile packet.
3. Upload `social-preview.png` under the main repository’s **Settings → General → Social preview**.
4. Apply the organization and repository metadata in [`GITHUB_LAUNCH_CHECKLIST.md`](./GITHUB_LAUNCH_CHECKLIST.md).
5. Confirm the README hero and screenshots render in GitHub light and dark modes.
